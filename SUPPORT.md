# Suporte

## Antes de pedir ajuda

1. Confirme a versão em `package.json` ou no instalador.
2. Reproduza com um workspace sintético e sem chaves reais.
3. Consulte [`README.md`](README.md), [`PRODUCT.md`](PRODUCT.md),
   [`ARCHITECTURE.md`](ARCHITECTURE.md) e [`SECURITY.md`](SECURITY.md).
4. Remova tokens, prompts, respostas, caminhos pessoais, logs e conteúdo de
   workspace antes de compartilhar qualquer diagnóstico.

## Bugs e melhorias

Use o template apropriado de Issue e inclua sistema operacional, versão,
passos mínimos e resultado esperado. Para problemas de segurança, não abra
Issue pública: siga [`SECURITY.md`](SECURITY.md).

## Distribuição da beta

A `v0.1.0-beta` é distribuída manualmente a partir de GitHub Releases. O
instalador Windows não é assinado nesta fase e pode exigir confirmação do
SmartScreen. A beta não possui updater automático; verifique o checksum
`SHA256SUMS` antes de instalar.
